# Changelog

All notable public changes to Tehseen Tech Manus Skills are documented here.

## [1.0.0] — 2026-08-16

### Added

- Public Tehseen Tech edition of the Manus Skills collection.
- 78 registered reusable skills organized across 13 categories and one meta-skill.
- Canonical `skills.json` registry with paths, descriptions, categories, authorship, dependencies, and complementary metadata.
- Automatic-discovery contract applied to all 78 skill descriptions.
- Documentation coverage for `Overview`, `Workflow`, and `Usage` sections where applicable.
- MIT license, Tehseen Tech attribution, professional PDF report, and validation artifacts.
- Repository-local validation script and GitHub Actions workflow.
- Contributor, security, support, code-of-conduct, issue-template, and pull-request guidance.
- Outcome-oriented quickstart and skill showcase documentation.

### Validation

The release was checked against the repository’s independent 78-skill verification requirements. The release scope is documentation, workflow guidance, metadata, registry content, scripts, and reusable skill instructions; external service behavior remains dependent on the user’s environment and credentials.
