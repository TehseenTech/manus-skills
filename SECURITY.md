# Security Policy

## Scope

This repository contains Markdown-based Manus AI agent skills, supporting scripts, registry metadata, and documentation. Security reports may concern malicious instructions, unsafe scripts, credential exposure, dependency issues, supply-chain risks, or documentation that could cause an agent to perform harmful actions.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use a private GitHub security advisory for this repository when available, or contact the Tehseen Tech maintainer through the private contact route on the GitHub profile. Include the affected path or skill, a concise description, reproduction steps or a minimal proof of concept, potential impact, and any suggested mitigation.

Remove credentials, personal data, client information, and other secrets from the report. If a report contains sensitive material, do not attach it to a public issue or pull request.

## Response expectations

The maintainer will acknowledge a credible report when practical, assess scope and severity, and coordinate a fix or mitigation before public disclosure where appropriate. Response timing may vary because this is a community-maintained public repository.

## Safe-use reminder

Skills are instructions and workflow aids, not a substitute for human review. Users should inspect scripts, references, external-service assumptions, credentials, and generated actions before running them in production or on sensitive data.

## Supported branch

Security fixes should target the current public `main` branch unless the maintainer provides different instructions.
