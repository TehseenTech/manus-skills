# Tehseen Tech Edition

## Brand and maintenance scope

This repository is presented as the **Tehseen Tech edition of Manus Skills**. Tehseen Tech is responsible for the current curation, metadata normalization, automatic-discovery update, registry reconciliation, documentation polish, and public packaging of this repository.

The repository contains skills collected from multiple workflows and sources. The Tehseen Tech attribution describes this edition’s curation and maintenance scope; it should not be interpreted as a claim that every upstream concept, dependency, or third-party integration originated with Tehseen Tech.

## Quality commitments

The public package is maintained around four commitments:

1. Every registered skill should resolve to a real `SKILL.md` file.
2. Every skill should expose clear frontmatter for discovery and routing.
3. Descriptions should explain capability, matching context, and automatic activation.
4. Registry changes should be validated before publication.
