# Tehseen Tech Manus Skills v1.0.0

Tehseen Tech is publishing the first public release of this Manus AI agent skill collection: **78 reusable skills across 13 categories and one meta-skill**.

## What is included

The release includes the canonical [`skills.json`](skills.json) registry, 78 `SKILL.md` files, automatic-discovery metadata, workflow and resource documentation, Python registry utilities, installation helpers, validation artifacts, a professional PDF report, MIT licensing, and contributor and security guidance.

## Why it is useful

The collection is designed for outcome-oriented work. Users can describe a research, engineering, automation, design, documentation, integration, or workflow need without first naming an internal skill. A compatible Manus environment can consider a matching skill automatically when the request fits its scope.

## Quality signals

The repository includes a local validator and a GitHub Actions workflow that check registry parity, frontmatter, Tehseen Tech authorship, automatic-trigger metadata, required documentation headings, and stale inherited repository references. These checks are guardrails, not a guarantee that every external service or generated action is safe for every environment.

Review scripts, credentials, external-service assumptions, licenses, and generated actions before production use. Do not include secrets or private client information in public issues or pull requests.
