# Support

## Choose the right channel

Use the following routes so questions reach the right place without exposing private information:

| Need | Recommended route |
|---|---|
| Reproducible defect | Open an issue with the bug-report template |
| New skill or improvement idea | Open an issue with the feature-request template |
| Proposed documentation or code change | Open a pull request using the project contribution guide |
| Security or credential concern | Follow [`SECURITY.md`](SECURITY.md); do not post details publicly |
| General usage question | Search the README, [`ARCHITECTURE.md`](ARCHITECTURE.md), and the relevant `SKILL.md`, then open a focused issue if the answer is missing |

## Before asking

Please include the repository commit or release you are using, the affected skill path, the request or workflow that triggered the issue, the expected result, the observed result, and the validation steps already attempted. Remove secrets, private data, tokens, customer information, and sensitive logs.

## What support can cover

The project can help clarify the public skill contract, registry structure, automatic-discovery metadata, documentation, installation scripts, and reproducible repository defects. Individual skills may depend on external services, accounts, APIs, or local environments that the maintainer cannot operate or guarantee.
